# سيستم مبيعات المطاعم — نسخة العرض (مطعم فرندس)

مش منيو. ده **سيستم** المنيو واجهته.
نسخة عرض بهوية وأصناف مطعم فرندس (بني سويف) — تتعرض على عملاء جداد.

## اللينكين

| اللينك | لمين | فيه إيه |
|---|---|---|
| `/` | العميل (QR على الترابيزة) | المنيو + الاقتراحات + السلة + الطلب على واتساب + التقييم + الولاء |
| `/owner.html` | صاحب المطعم | الأرقام: الأصناف الميتة، أوقات الذروة، القمع، الأب-سيل، الطلبات، العملاء، التحكم الفوري، حاسبة العائد |

## اللي بيبيع (واجهة العميل)
- **إضافات مدفوعة** مع كل صنف — اللي الويتر بينساها
- **"يتحلى مع…"** اقتراح تلقائي من قسم تاني
- **كومبوهات** بسعر موفّر
- **بادچات**: الأكثر طلباً / ترشيح الشيف / جديد
- **عرض النهاردة بعدّاد وقت** — استعجال حقيقي
- **اقتراح أخير في السلة** قبل الإرسال
- **الطلب على واتساب** برقم الترابيزة أو العنوان
- **فلتر التقييمات**: ٤ نجوم فأكتر → جوجل، أقل → واتساب الأونر قبل ما تتنشر
- **كارت ولاء + كوبون** للزيارة الجاية

## اللي بيقيس (لوحة الأونر)
- الفلوس اللي السيستم زوّدها (أب-سيل + إضافات)
- زوار / طلبات / متوسط الفاتورة / نسبة قبول الاقتراح
- أوقات الذروة بالساعة + أيام الأسبوع
- قمع التحويل: فتح المنيو ← فتح صنف ← ضاف للسلة ← بعت
- أكتر الأصناف مشاهدة × أكتر الأصناف إيرادًا
- **الأصناف الميتة** (٠ مشاهدة) — أقوى ورقة في الاجتماع
- **اتشاف كتير ومحدش طلبه** = مشكلة سعر/وصف
- قاعدة أرقام العملاء + تصدير CSV
- تحكّم فوري: خلص الصنف / غيّر سعر / شغّل عرض
- حاسبة العائد

## تقني
- HTML/CSS/JS خالص — من غير باك-إند ولا build
- البيانات: `data/menu.js` (المنيو) + `data/sales.js` (طبقة المبيعات — عدّلها لأي مطعم)
- التتبّع في `localStorage`، وبيتزامن لحظيًا بين تاب العميل وتاب الأونر (`BroadcastChannel`)
- للنسخة الحقيقية: حط رابط Google Apps Script في `SALES.endpoint` والأحداث تتبعت لشيت حقيقي
- اللوحة بتفتح على **٣٠ يوم بيانات تجريبية** عشان العرض؛ فيه زرار يحوّلها للبيانات الحقيقية بس
